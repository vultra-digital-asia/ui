Visual video editor for Svelte — like Remotion Studio, built on the @vultra/motion ecosystem.

## Install

```bash
npm install @vultra/motion-studio
```

## Usage

```svelte
<script>
  import { MotionStudio } from '@vultra/motion-studio';
</script>

<MotionStudio composition={myComposition} />
```
