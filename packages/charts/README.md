[![npm version](https://img.shields.io/npm/v/@vultra/charts?style=flat-square&color=7c3aed)](https://www.npmjs.com/package/@vultra/charts)

[![License MIT](https://img.shields.io/npm/l/@vultra/charts?style=flat-square&color=7c3aed)](https://github.com/vultra-digital-asia/ui/blob/main/LICENSE)


Chart components for Vultra UI (Chart.js wrapper) — line, bar, pie, doughnut, and more.

## Install

```bash
npm install @vultra/charts
```

## Usage

```svelte
<script>
  import { LineChart } from '@vultra/charts';
</script>

<LineChart data={[{ x: 1, y: 2 }, { x: 2, y: 5 }]} />
```
