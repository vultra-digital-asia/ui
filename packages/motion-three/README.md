Three.js addon for @vultra/motion — 3D rendering inside video compositions.

## Install

```bash
npm install @vultra/motion-three
```

## Usage

```svelte
<script>
  import { ThreeScene } from '@vultra/motion-three';
</script>

<ThreeScene scene={myScene} />
```
