# @vultra/grid-core

Shared grid infrastructure for Vultra UI — TanStack Table + virtual scrolling + keyboard navigation + clipboard support, the engine under `@vultra/data-table`.

## Install

```bash
npm install @vultra/grid-core
```

## Usage

```svelte
<script>
  import { DataTable } from '@vultra/grid-core';
  // or the lower-level Grid primitives
</script>
```

`@vultra/data-table` builds on this package for an enterprise-grade data grid. See its README for the full feature set.
