PDF viewer component with annotations, form filling, and editing for Vultra UI.

## Install

```bash
npm install @vultra/pdf-viewer
```

## Usage

```svelte
<script>
  import { PDFViewer } from '@vultra/pdf-viewer';
</script>

<PDFViewer src="/document.pdf" />
```
