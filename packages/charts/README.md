# @vultra/charts

Chart components for Vultra UI (Chart.js wrapper) — line, bar, pie, doughnut, and more.

## Install

```bash
npm install @vultra/charts
```

## Usage

```svelte
<script>
  import { LineChart } from '@vultra/charts';
</script>

<LineChart data={[{ x: 1, y: 2 }, { x: 2, y: 5 }]} />
```
