CSS effects and transitions for @vultra/motion — reusable visual effect presets for video composition.

## Install

```bash
npm install @vultra/motion-effects
```

## Usage

```svelte
<script>
  import { Effect } from '@vultra/motion-effects';
</script>

<Effect name="blur-in" />
```
