# @vultra/collaboration

Real-time collaboration and version history for book-writer — presence, live cursors, and document snapshots.

## Install

```bash
npm install @vultra/collaboration
```

## Usage

```svelte
<script>
  import { CollaborationProvider } from '@vultra/collaboration';
</script>

<CollaborationProvider documentId="doc-1" />
```
