Presentation editor with slides, transitions, and export for Vultra UI.

## Install

```bash
npm install @vultra/slides
```

## Usage

```svelte
<script>
  import { SlidesEditor } from '@vultra/slides';
</script>

<SlidesEditor slides={[{ title: 'Intro', content: '…' }]} />
```
