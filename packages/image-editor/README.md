# @vultra/image-editor

Image editor with filters and effects for Vultra UI — crop, rotate, and a filter/effect pipeline.

## Install

```bash
npm install @vultra/image-editor
```

## Usage

```svelte
<script>
  import { ImageEditor } from '@vultra/image-editor';
</script>

<ImageEditor src="/photo.jpg" />
```
